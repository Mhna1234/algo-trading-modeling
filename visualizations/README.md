# Visualizations

This folder contains visualization outputs from benchmark strategy backtests.

**Last Updated**: December 15, 2025 (v3.0.0)

---

## Current Files

### Fast Demo Visualizations (6 months, weekly rebalancing)
Generated by `examples/demo_12_strategies_fast.py`:

- **12_strategies_fast_nav_curves.png** - NAV curves for all 12 strategies (normalized to 100)
- **12_strategies_fast_metrics_comparison.png** - 6-panel metrics comparison (CAGR, Sharpe, Volatility, Max DD, Calmar, Sortino)

## Benchmark Strategies (12 Total)

All visualizations include results for these validated strategies:

1. **Buy & Hold** - Market cap weighted benchmark
2. **Equal Weight** - Naive 1/N allocation
3. **Quintile Momentum** - Top 20% performers
4. **Quintile Low Volatility** - Bottom 20% volatility
5. **Mean Reversion** - Contrarian quintile
6. **Global Minimum Variance** - Minimum portfolio volatility
7. **Inverse Volatility** - Inverse volatility weighting
8. **Risk Parity** - Equal risk contribution
9. **Maximum Diversification** - Maximize diversification ratio
10. **Maximum Decorrelation** - Minimize correlations
11. **Sharpe Maximization** - Mean-variance optimization
12. **CVaR Minimization** - Conditional VaR optimization

## Visualization Details

### NAV Curves
- Normalized to 100 at start date
- Shows cumulative performance over backtest period
- Includes all 12 strategies on one chart for comparison

### Metrics Comparison
Six-panel chart with bar comparisons:
1. **CAGR** (Compound Annual Growth Rate)
2. **Sharpe Ratio** (risk-adjusted returns)
3. **Volatility** (annualized standard deviation)
4. **Max Drawdown** (peak-to-trough decline)
5. **Calmar Ratio** (CAGR / Max Drawdown)
6. **Sortino Ratio** (downside risk-adjusted returns)

### Correlation Heatmap
- Strategy returns correlation matrix
- Color-coded from -1 (negative) to +1 (positive)
- Helps identify diversification benefits

## Usage

### Generate Fast Demo Visualizations (6 months)
```bash
python examples/demo_12_strategies_fast.py
```
- Execution time: ~30-60 seconds
- Weekly rebalancing
- Output: `12_strategies_fast_*` files

### Generate Full Demo Visualizations (10 years)
```bash
python examples/demo_12_strategies_full.py
```
- Execution time: ~3-4 minutes
- Monthly rebalancing
- Output: `12_strategies_full_metrics_YYYYMMDD_HHMMSS.*` files

### Bandit Allocation Demos
```bash
python examples/demo_bandit_strategy_wrapper.py   # MAB allocation
python examples/demo_bandit_comparison.py         # UCB vs Thompson
```

## File Organization

### Naming Convention
- **Fast demos**: `12_strategies_fast_*.{png,csv,json}`
- **Full demos**: `12_strategies_full_metrics_YYYYMMDD_HHMMSS.{csv,json}`
- Timestamped files preserve historical results

### Retention Policy
- Keep latest full demo results (most recent timestamp)
- Keep all fast demo results (no timestamps, overwritten each run)
- Archive or delete older timestamped results as needed

## Data Formats

### CSV Export
Complete metrics table with columns:
- Strategy name
- CAGR, Total Return, Sharpe, Sortino, Calmar
- Volatility, Max Drawdown
- Win Rate, Profit Factor, Turnover
- Number of trades, final allocation, HHI

### JSON Export
Nested dictionary structure:
```json
{
  "Buy & Hold": {
    "CAGR": 0.1725,
    "Sharpe Ratio": 0.904,
    ...
  },
  ...
}
```

## Notes

- All visualizations saved at 300 DPI for publication quality
- PNG format for charts, CSV/JSON for metrics
- Full demo uses timestamped filenames to preserve history
- Fast demo overwrites previous results for quick iteration
- Charts use seaborn styling with the "husl" color palette
- Visualizations are automatically regenerated when tests/scripts are run
