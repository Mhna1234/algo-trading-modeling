# Visualizations

This folder contains all visualization outputs from the algorithmic trading project.

## Test Visualizations (from `test_portfolio_integration.py`)

Generated by running the integration test suite with visualization enabled.

### Single Strategy Analysis
- **test_equity_curve.png** - Portfolio equity curve over time showing capital growth
- **test_portfolio_weights.png** - Asset allocation weights over time (stacked area chart)
- **test_drawdown.png** - Portfolio drawdown from peak equity levels
- **test_returns_distribution.png** - Histogram of daily returns with mean indicator
- **test_performance_summary.png** - Comprehensive performance metrics summary table

### Multi-Strategy Comparison
- **test_strategy_comparison.png** - 4-panel comparison:
  - Equity curves for all strategies
  - Sharpe ratio comparison (horizontal bar chart)
  - Return vs Risk scatter plot
  - Total return comparison (horizontal bar chart)
- **test_strategy_drawdowns.png** - Overlaid drawdown curves for all strategies

Strategies compared:
1. Equal Weight (1/N allocation)
2. Momentum Top-2 (invest in 2 best performers)
3. Momentum Top-3 (invest in 3 best performers)
4. Tangency 60d (Max Sharpe with 60-day lookback)
5. Tangency 120d (Max Sharpe with 120-day lookback)
6. MVO 5% target (Mean-variance optimization targeting 5% annual return)
7. MVO 15% target (Mean-variance optimization targeting 15% annual return)

## Main Pipeline Visualizations (from `visualize_portfolio.py`)

Generated by running `visualize_portfolio.py` or calling visualization functions in `main.py`.

- **equity_curves.png** - Portfolio performance vs benchmark comparison
- **portfolio_weights.png** - Weight allocation evolution over the backtest period
- **risk_metrics.png** - Multi-panel risk analysis:
  - Drawdown chart
  - Rolling volatility
  - Risk-adjusted returns metrics
- **trading_activity.png** - Trading turnover and rebalancing activity analysis
- **correlation_analysis.png** - Asset correlation matrix heatmap
- **monthly_returns.png** - Calendar heatmap of monthly returns

## Usage

### To generate test visualizations:
```bash
python test_portfolio_integration.py
```

### To generate main pipeline visualizations:
```bash
python visualize_portfolio.py
```

Or programmatically:
```python
from visualize_portfolio import plot_equity_curves, plot_portfolio_weights, plot_risk_metrics

# After running backtest
plot_equity_curves(portfolio_result, benchmark_prices)
plot_portfolio_weights(weights_df)
plot_risk_metrics(portfolio_result)
```

## Notes

- All visualizations are saved at 150 DPI (test) or 300 DPI (main pipeline) for high quality
- Charts use seaborn styling with the "husl" color palette
- Visualizations are automatically regenerated when tests/scripts are run
- Old files are overwritten to maintain a clean folder structure
